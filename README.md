# Pho-Vietnamese-Web-Page-
The first ever web page that I built in the FreeCodeCamp Responsive Web Design Course that uses HTML. This is about how the user can cook a simple Vietnamese dish of Pho bring in the external images and using a basic HTML web page structure. This uses the unordered list and ordered list along with an embedded website link. 

# Concepts Learned:

* Basic HTML Web Page Structure
* Unordered List element
* Strong Element
* Embedded External Image element
* Figure and Figcaption Elements
* Embedded External Website Links
* Ordered List Element
* Em Element
* alt, width, and height attributes
